> **Release Status**: Published on 2026-10-08  
> **Package Version**: `1.0.0`

> **Trace Report Schema**: `0.5`  
> **Fingerprint Report Schema**: `0.1`  
> **Compare Report Schema**: `0.1`  

---

## Overview

SkillLineage is an open-source, deterministic tool for identifying how AI Agent Skills (`SKILL.md`) relate to one another across repositories and agent ecosystems. It provides deterministic fingerprinting, pairwise skill comparison, and global multi-tier tracing against GitSkills-derived index shards.

SkillLineage reports structured evidence without inferring original authorship, copyright ownership, fork direction, or malicious intent without explicit historical proof.

---

## Key Highlights in v1.0.0

- **Zero Production Dependencies**: The core package and CLI run purely on the Node.js standard library (`node >= 22`).
- **Deterministic Fingerprinting**: Generates canonical Git blob SHA-1 hashes, frontmatter-agnostic normalized instruction SHA-256 digests, complete skill bundle hashes, and directory inventory records.
- **Pairwise Skill Comparison**: Classifies relationships between local skills (`identical_bundle`, `same_skill_md`, `same_instructions`, `variant`, `different`) using 5-token shingle Jaccard similarity.
- **Multi-Tier Trace Engine**: Deterministic match precedence (`exact` raw Git blob -> `same_instructions` normalized body -> `variant_candidates` approximate shingles -> `none`).
- **Approximate Variant Retrieval**: Bottom-32 token shingle sketching (`bottom-k-token-shingles-v1`) with 5-token shingles, SHA-256-96 hashing, SHA-256 anchor routing, and four-hex micro-sharding.
- **Precomputed Variant Enrichment**: Instant candidate metadata presentation without secondary shard scans.
- **Observed Historical Evidence**: UTC-normalized earliest and latest dataset observations with location-level coverage accounting (`none`, `partial`, `complete`).
- **Pairwise Temporal Observation Evidence**: Deterministic observation-order relations across final variant candidates based on stored dataset history.
- **Evidence Graph Projection**: Machine-readable graph serialization capturing query similarity edges and candidate-to-candidate temporal observation edges without unauthorized directional lineage claims.
- **Deterministic Evidence Summary**: Synchronous, human-readable summary projection (`evidenceSummary`) articulating match facts and explicit epistemic limitations with zero LLMs or extra I/O.
- **Frozen Public Runtime API**: 27 frozen root exports with strict TypeScript `NodeNext` declarations and ESM-only packaging.

## Installation & System Requirements

- **Runtime Requirement**: Node.js `>= 22`
- **Zero Runtime Dependencies**: No native modules, no production npm dependencies.

### CLI Usage

Install SkillLineage from npm, or run the released version with `npx`:

```bash
# Direct execution without prior install
npx skilllineage --version
npx skilllineage --help

# Fingerprint a skill directory
npx skilllineage fingerprint ./path/to/skill

# Compare two local skills
npx skilllineage compare ./skill-a ./skill-b

# Trace against a local GitSkills index
npx skilllineage trace ./my-skill --index ./gitskills-index
```

### Programmatic ESM / TypeScript Usage

```typescript
import {
  VERSION,
  fingerprint,
  compareSkills,
  traceSkill,
  type FingerprintReport,
  type CompareReport,
  type TraceReport,
} from "skilllineage";

// Fingerprint
const fpReport: FingerprintReport = await fingerprint("./path/to/skill", VERSION);

// Compare
const cmpReport: CompareReport = await compareSkills("./skill-a", "./skill-b", VERSION);

// Trace against a schema-0.5 index
const traceReport: TraceReport = await traceSkill("./my-skill", "./gitskills-index", VERSION);
```

## Index Requirements & Availability

- The npm package provides the CLI and analysis runtime. It does **not** bundle pre-built GitSkills index data due to dataset scale. For a runnable synthetic first-use example, see the [Quickstart](https://github.com/mehdimt1980/skilllineage/blob/main/docs/quickstart.md).
- The `trace` command requires a local index directory formatted under **index schema 0.5** passed via `--index <dir>`.
- Indexes are generated from the [GitSkills dataset](https://huggingface.co/datasets/mvaccargiu/gitskills) using the repository's offline builder (`python tools/build-gitskills-index.py <db> <dir>`), run from a source repository checkout with a GitSkills SQLite database. The offline Python builder is not included in the npm package.

---

## Epistemic Principles & Limitations

- **Evidence Over Claims**: Reports describe observations in the indexed dataset, not global historical certainty outside the dataset.
- **Invariant**: Every trace report maintains `{ "origin": { "status": "not_inferred" } }`.
- **No Plagiarism or Derivation Inferences**: High textual similarity or matching hashes do not prove original authorship, copy direction, or malicious intent.

| **Trace report schema** | `0.5` | JSON report format for `traceSkill` |
| **Fingerprint report schema** | `0.1` | JSON report format for `fingerprint` |
| **Compare report schema** | `0.1` | JSON report format for `compareSkills` |
